Problem Statement

Understanding human emotions in real time is critical for mental health monitoring, human–computer interaction, surveillance, and behavioral analysis. Traditional methods rely on manual observation, which is slow and inaccurate. An automatic facial emotion recognition system can help identify emotional states like happiness, sadness, anger, fear, and surprise with real-time predictions.

Working Process

  • Face is captured through webcam input
  • Deep learning model processes the facial ROI
  • Emotion categories: Happy, Sad, Angry, Neutral, Surprise, Fear
  • Probability distribution is calculated for each emotion
  • Real-time emotion label is displayed on screen

Technologies Used

Python | TensorFlow | Keras | OpenCV | NumPy | HTML | CSS | JavaScript | GitHub

Results

The system accurately predicts facial emotions in real time with good precision. It works across different lighting conditions and multiple face orientations, making it reliable for practical applications.
