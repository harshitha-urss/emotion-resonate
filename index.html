Welcome to Emotion Resonate

Emotion Resonate is an AI-powered application that helps users understand and respond to their emotions in real time. The app detects your emotional state and instantly provides a supportive message along with a mood-matching avatar.

🎯 This app detects and responds to your emotions using AI. Choose your comfort: Analyze your mood through Text, Face, or Voice.

  • 📝 Text Analysis: Type a message and get instant mood and support.
  • 📷 Face Analysis: Use your webcam for live mood detection or photo capture.
  • 🎤 Voice Analysis: Speak to sense your mood and get feedback.
  • 🔒 Privacy First: All analysis runs locally in your browser. No data leaves your device.

Problem Statement

Many individuals struggle to understand and manage their emotional state in real time. Traditional emotional support systems often lack instant feedback, privacy, and accessibility. There is a need for a smart, privacy-preserving AI system that can detect emotions instantly and provide supportive, empathetic responses through multiple input modes.

Working Process

  • User selects input mode: Text, Face, or Voice
  • Input is processed locally inside the browser
  • AI model analyzes emotional patterns
  • Emotion is classified (Happy, Sad, Angry, Neutral, Fear, Surprise)
  • Supportive feedback and mood-matching avatar are displayed
  • No data is sent to any external server (privacy preserved)

Technologies Used

React | JavaScript | TensorFlow.js | Web Speech API | WebCam API | HTML | CSS | GitHub | Netlify

Results

The Emotion Resonate system successfully detects emotions from text, face, and voice inputs in real time. The avatar-based emotional feedback enhances user engagement, while the privacy-first local execution ensures complete data security. The application performs smoothly across modern browsers with high responsiveness.
